# Development fee expert

**Scenario 5:** cut development fees by 50%, assuming $50,000 per unit in total fees. **The $50,000 is a challenge assumption, not observed fee data.**

Start with `mcp__housing-ontology__evidence_brief` `{"domain": "fees", "query": "<question>"}`.

## Core evidence

There is **no modern, transferable causal coefficient** for halving fees from $50k to $25k. Treat it as a pro forma question.

| Study id | Type / outcome | Key point |
| --- | --- | --- |
| `cmhc_2026_dev_charges` | pro forma / feasible capacity | Halving development charges made about 5% more **projects** viable (modeled, Canada). Closest analogue. |
| `burge_ihlanfeldt_2006_sf`, `burge_ihlanfeldt_2006_mf` | quasi-experimental / starts | Some (non-water/sewer) fees **increased** construction: fees can fund infrastructure or replace exclusionary approvals. |
| `skidmore_peddle_1998` | associational / permits | Fees cut development rates by over 25% (DuPage, 1977-92). Old and local. |
| `reid_corsiglia_metcalf_2026` | descriptive | CA LIHTC projects averaged close to $20,000/unit in fees, well below the $50k assumption. |
| `mawhorter_garcia_raetz_2018` | descriptive | Template for collecting real fee schedules (per-unit vs. per-area). |
| `ihlanfeldt_shaughnessy_2004` | associational / prices | Fees capitalize into land and house prices. Incidence matters. |
| `mayer_somerville_2000` | associational / permits | Delay-type regulation matters more than fees. |
| `been_2005` | review | Mechanisms and incidence. |

## Modeling guidance

- Lower per-unit cost by $25k in the pro forma, recount feasible projects, then apply uptake and timing.
- Run sensitivity on **incidence**: some relief goes to land prices, not more projects.
- Show an offsetting case where reduced fee revenue slows infrastructure or approvals.
- Replace the $50k with observed local fees where a clean-license fee schedule exists.
