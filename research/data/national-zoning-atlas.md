## Description

Standardized, district-level coding of zoning codes: permitted housing types (1-, 2-, 3-, 4+ family), by-right versus hearing, ADU allowance, minimum lot size, and parking requirements, mapped to district boundaries.

## Known limitations

- **Coverage is incomplete**, so not every state or jurisdiction is coded. We need a fallback for uncovered areas, such as state-average assumptions or LOCUS ordinance text (see papers).
- Codes change. A snapshot may predate recent state preemption laws.
- Coding simplifies nuance (overlays, conditional uses, design standards).
