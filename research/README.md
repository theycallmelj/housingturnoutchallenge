# Research

- [`papers/`](papers/README.md) is the literature on comparative housing policy, organized by the five benchmark scenarios. Run `./research/papers/fetch_papers.sh` to download the PDFs (gitignored).
- [`data/`](data/README.md) has one provenance file per candidate data source, covering name, URL, description, license, and limitations. Raw data is gitignored and must be fetched by a script.

See [`../AGENTS.md`](../AGENTS.md) for the provenance and disclosure rules every contributor must follow.
